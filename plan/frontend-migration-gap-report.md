## 二、整页缺失

### 1. 节点管理页 `/nodes` ✅ 已补齐（2026-07-29）

- 旧前端：`web-backup/src/views/node/index.vue`（路由 `/nodes`，仅管理员）
- 新前端：已实现于 `web/src/views/node/`（API 封装 `web/src/api/node.ts`，文档 `docs/node-page.md`）。
- 后端接口存在（`listNodes / createNode / updateNode / deleteNode / probeNode`），未改动后端。

旧页面完整功能清单（已全部移植）：

| 功能 | 说明 |
| --- | --- |
| 节点列表表格 | 名称 / 面板 API 地址 / SSH（user@host:port）/ 状态标签（在线/异常/未知）/ 最近探测消息 / 启用状态 |
| 筛选 | 名称搜索、状态筛选、启用状态筛选，筛选变化重置分页 |
| 添加/编辑节点弹窗 | 名称、面板 API 地址、API ID、API Key（编辑时留空不改）、SSH 地址/端口/用户、root 密码（编辑时留空不改）、启用开关 |
| 探测节点 | 单行"探测"按钮，行级 loading，探测后刷新列表 |
| 删除节点 | 二次确认后删除 |
| 移动端适配 | ≤768px 切换卡片视图 |

补齐时注意：root 密码输入框需接入密码泄露检测函数（项目规范第 22 条）；行内操作按「纯图标 + Tooltip」模式（规范第 28 条）。

## 三、页面内功能缺失

### 2. 虚拟机列表页 🟠

新前端 `web/src/views/vm/index.tsx` 主体功能完整（SSE 实时、双视图、批量电源、锁定/救援/导出/转独立/迁移/重装/制作模板等均已移植），但以下旧功能缺失：

| 功能 | 旧前端位置 | 缺失状态 |
| --- | --- | --- |
| **搜索框** ✅ | `list.vue` 顶部 `vmSearchText`（搜名称/备注/模板） | 已补齐（2026-07-29）：工具栏中部搜索框，客户端过滤名称/备注/模板 |
| **分组视图** ✅ | `list.vue` `vmGroupBy`（按状态/按模板/自定义分组/全部），支持组折叠、组内全选 | 已补齐（2026-07-29）：`VmGroupedView.tsx`，表格/卡片均支持，组折叠+全选本组+跨组多选，`vmListGroupBy` 持久化 |
| **磁盘占用按需加载** | `loadVmDiskUsage`（"查看占用"→ 显示已用 GB） | 完全缺失，新版列表无入口 |
| **连续运行时间列** | `formatContinuousRuntime` 列 + 开始时间 tooltip | 列表中缺失（详情页 InfoTab 已有） |
| **创建时间列排序** | `created_at` 列可排序，默认按创建时间倒序 | 新版排序字段仅 名称/资源使用率/IP，无创建时间 |
| IP 不可达原因提示 | `ipTooltipText`（vlan_bridge 桥接模式提示"上游路由器分配的 IP 无法从宿主机获取"） | 新版 `VmIpCell` 仅显示 IP 或"未分配"，无原因提示（低风险） |

### 3. 管理员首页（Dashboard） 🟠

新前端实时/历史监控四图、统计卡、SMTP 警告、密码泄露状态、最近虚拟机均已移植，缺失：

| 功能 | 旧前端位置 | 缺失状态 |
| --- | --- | --- |
| **挂载磁盘空间表格** | `dashboard/index.vue` "挂载磁盘空间" 区块（`getHostDisks`：挂载点/设备/文件系统/使用率进度条/已用÷总容量） | 完全缺失。`getHostDisks` API 定义仍在 `web/src/api/host.ts` 但全站无调用 |
| **磁盘 IO 延迟卡片** | 实时监控区第 4 张环卡（`disk_io_latency_ms`，>5ms 黄 >10ms 红） | 缺失。SSE 数据里有该字段（`HostStats.disk_io_latency_ms`）但无任何 UI 展示 |

> 注：管理员工作台此前有过 UI 精简调整，若这两项属于有意精简可从待办中划掉，建议确认。

### 4. 网络中心（含旧 /ovs 页面遗留） 🟡

新前端 `web/src/views/network` 已整合 OVS 概览/交换机/安全组/ACL，且新增了主机网卡配置、网桥管理等增强。旧 `/ovs` 页（注：旧路由已将 `/ovs` 重定向到 `/network`，独立入口本已隐藏）中以下细节未落入新版网络概览：

| 功能 | 旧前端位置 | 缺失状态 |
| --- | --- | --- |
| **全局 DHCP 静态绑定 / 租约 / 租约冲突表** | `ovs/index.vue`（`getOVSLeases`：static_hosts、dhcp_leases、conflicts 三张表，冲突含类型/IP/MAC/说明） | 网络概览无全局维度展示；VM 详情网络 Tab 仅有单机维度的静态绑定和租约。**租约冲突检测完全无处可看** |
| **系统环境 / OVS 依赖卡** | `ovs/index.vue`（发行版/内核/架构 + OVS 包名/服务/安装命令一键复制，未安装时告警） | 缺失。关于页有部分系统信息，但 OVS 安装引导没有 |
| NAT/FORWARD 规则明细表 | `ovs/index.vue`（规则名/存在状态/检查命令） | 新版 OverviewTab 仅保留 ip_forward/NAT/dnsmasq 布尔状态，检查命令明细缺失（低风险） |
| 修复建议列表 | `checkOVSNetwork` 返回的 `repair_suggestions` 标签 + 最近修复任务提示 | 新版检测后仅 Toast 提示通过/完成，建议明细未展示（低风险） |
