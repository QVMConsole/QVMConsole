# 虚拟机详情页配置 SSE 实时同步

## 功能说明

虚拟机详情页复用 `/vm/:name/sse` 长连接作为统一实时信号。服务端每次推送有效的 `vm_detail` 事件后，前端除更新虚拟机基础详情和监控数据外，还会静默同步当前正在查看的配置标签，因此无需刷新整个页面。

纳入同步的详情区域包括：

- 系统信息中的 PCIe 热插槽、全部网口 IP 和磁盘 IOPS；
- 快照列表与配额；
- 网络管理中的 VPC、静态 IP、运行状态、转发规则和诊断信息；
- 定时任务列表；
- VNC 与 SPICE 状态；
- 编辑页全部共享表单、磁盘/光驱/软盘、磁盘 IOPS、VPC 与多网口动态表单。

只有当前可见的一级标签及当前可见的网络子标签会请求附属数据，避免已经访问但位于后台的标签持续产生无效请求。断线时沿用详情 SSE 的 5 秒重连机制，连接恢复后自动继续同步。

## 编辑中的输入保护

编辑页会为服务端表单配置、直通设备、SPICE 状态和磁盘信息生成配置签名：

1. 仅 CPU、内存等资源统计发生变化时，不重建表单；
2. 服务端配置确实变化时，表单才更新为最新配置；
3. 内存运行状态和 Guest Agent 连接状态独立更新；
4. 用户尚未提交的磁盘 IOPS 草稿会在后台同步磁盘列表时保留；
5. VPC 选择仅在服务端绑定变化时回填，普通 SSE 心跳不会覆盖尚未保存的选择。

## 页面变化

“系统信息 → 磁盘 IOPS 限制”标题旁的刷新按钮已移除。磁盘列表和 IOPS 状态由 SSE 信号自动同步，首次加载仍显示加载状态，后续同步不会闪烁加载动画。
