# 安装时选择用户存储磁盘

`install.sh` 初始化“我的存储”配额文件系统时，会在创建镜像前显示磁盘选择菜单。

## 选择规则

- 菜单默认选项为根目录，行为与旧版一致：在 `/var/lib/kvm-user-storage.img` 创建稀疏镜像。
- 其余选项为已挂载、可写的本地 `ext4`、`xfs` 或 `btrfs` 文件系统。菜单会显示设备、挂载点、文件系统类型与可用空间。
- 未挂载、只读或非本地文件系统不会显示。请先在系统中挂载该磁盘，或在“存储池”页面完成磁盘初始化和挂载后重新执行安装脚本。
- 选择非根目录后，镜像创建为 `<所选挂载点>/kvm-user-storage.img`，配额挂载点仍固定为 `/var/lib/kvm-user-storage`，不影响现有用户目录和配额逻辑。

## 兼容与升级

- 已存在的用户存储镜像会从 `/etc/fstab` 或当前 loop 挂载自动识别并复用，不会再次显示磁盘选择菜单，也不会迁移或覆盖数据。
- 安装脚本会将最终镜像路径写入 `/opt/kvm-console/.env` 的 `KVM_USER_STORAGE_IMAGE`，服务运行期的自动挂载与存储回收会使用该路径。
- `/etc/fstab` 中由面板管理的用户存储挂载条目会保持单条，避免重复挂载配置。
