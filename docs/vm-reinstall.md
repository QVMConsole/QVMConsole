# 虚拟机重装系统

重装系统通过异步任务执行，操作前需要完成高风险二次验证。任务会保留虚拟机的硬件配置、数据盘、主网口绑定和所属 VPC，仅替换系统盘并基于所选模板完成初始化。

## 网络配置同步

重装会先读取并保存虚拟机的原始持久化 XML，关闭虚拟机后创建新的系统盘。正式开机前，任务会按主网口的 VPC 绑定同步持久化 XML：

1. 未绑定 VPC 时，保留现有网络 XML。
2. 绑定普通 VPC 或系统基础网络时，将主网卡切换到 OVS 网桥并写入对应 VLAN。
3. 绑定桥接直通交换机时，保留或同步到该直通桥接配置；主网卡已连接目标网桥且 VLAN 无需调整时，视为同步成功。
4. Windows 的 Config Drive 与首次冷重启策略会先合并到同一份 XML，再写入持久化配置，避免互相覆盖。

因此，历史配置中出现“VPC 绑定记录为普通 VPC、XML 主网卡仍为桥接直通”的情况时，重装不会在虚拟机已经启动后才尝试切换网络，也不会触发运行态切换必须关机的限制。对于历史 `bridge` 或 libvirt `network` 类型主网卡，任务会在关机态转换为 OVS 网桥网卡后再应用目标 VPC 配置。

## 失败回滚

如果系统盘创建、VPC 网络配置同步或首次启动失败，任务会强制关闭虚拟机，并恢复重装前的系统盘与最初保存的持久化 XML。VPC 交换机不存在，或 XML 中没有可转换为 OVS 的 `bridge` / `network` 主网卡时，任务会在开机前失败并进入回滚，以避免虚拟机带着错误网络配置启动。

本功能未新增安装依赖、数据库字段或 API 接口。
