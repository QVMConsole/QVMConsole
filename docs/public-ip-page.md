# 公网 IP 页（新前端）

> 对应路由：`/public-ip`（仅管理员）
> 源码目录：`web/src/views/public-ip/`
> 旧版对照：`web-backup/src/views/public-ip/index.vue`

## 功能总览

| 功能 | 说明 |
|------|------|
| 角色限制 | 仅管理员可访问（页面内非管理员显示无权限提示，与模板页一致；后端接口由 AdminMiddleware 保护） |
| 页头操作 | 刷新 / 重载规则（高风险确认，提交任务队列）/ 新增公网 IP |
| 顶部提示 | 绑定、解绑、迁移触发高风险验证并走任务队列；经典网络需上游支持，VM 内 IP 用户手动配置 |
| 筛选 | 公网 IP 搜索、状态筛选（已绑定/空闲/保留）、模式筛选（1:1 NAT/经典网络-路由/经典网络-桥接），客户端分页 100 条/页 |
| 列表 | 公网 IP、掩码/网关、出口网卡、支持模式（标签）、状态、绑定 VM（名称+模式/用户/私网/运行态）、备注 |
| 行内操作 | 高频「绑定」（空闲）/「迁移」（已绑定）图标外露；其余收进 ⋯ 下拉：编辑、预览/试算规则、解绑（已绑定，危险）/删除（未绑定，危险） |
| 新增/编辑 | IP、CIDR/掩码、网关、出口网卡、支持模式多选、状态（空闲/保留）、备注；已绑定行禁止修改 IP 与状态（与后端约束一致） |
| 绑定/迁移 | 用户 → 虚拟机联动过滤（归属来自用户列表 vms 字段）；绑定模式限定为该 IP 支持的模式；VM 私网 IP（NAT 必填，留空后端自动解析）；可先预览规则再提交任务 |
| 规则预览 | 已绑定行直接预览当前绑定关系规则（nftables/路由命令 + 配置提示 + 警告）；未绑定行进入绑定弹窗试算 |
| 解绑/删除/重载 | confirmModal 确认后执行；解绑/重载提交任务队列后延迟 1.2s 刷新列表 |

## 目录结构

```
web/src/views/public-ip/
├── index.tsx                        # 主入口：数据加载/筛选/表格/操作/弹窗分发
├── public-ip.css                    # 页面样式（深空极光，浅色优先 + 深色适配）
├── utils.ts                         # 模式标签/状态映射/任务提示文案
└── dialogs/
    ├── PublicIpDialog.tsx           # 新增/编辑公网 IP
    └── BindPublicIpDialog.tsx       # 绑定/迁移（含规则预览面板）
```

相关共享模块：

- `web/src/api/publicIp.ts`：公网 IP CRUD、预览、绑定/解绑/迁移、重载接口（新建）
- `web/src/api/user.ts`：`UserListItem` 新增 `vms?: string[]` 字段（管理员接口返回的用户已分配 VM 名称，用于绑定弹窗 VM 归属过滤）

## 涉及接口（均为管理员）

- `GET/POST /network/public-ips`、`PUT/DELETE /network/public-ips/:id`：公网 IP 资源管理
- `POST /network/public-ips/:id/preview`：绑定规则预览（试算）
- `POST /network/public-ips/:id/bind`、`/unbind`、`/migrate`：绑定/解绑/迁移（高风险 428 二次验证，任务队列异步应用）
- `POST /network/public-ips/apply`：按当前绑定关系重载全部规则（高风险）
- `GET /user/list`、`GET /vm/list`：绑定弹窗的用户与虚拟机选项

## 与旧版差异

1. **移动端卡片移除**：旧版表格 + 移动端卡片双视图，新版统一为响应式表格（小屏横向滚动），与网络页策略一致。
2. **行内操作收折**：旧版 6 个文字按钮平铺，新版按「纯图标 + Tooltip + ⋯ 下拉」规范收折（仅高频绑定/迁移外露），危险项（解绑/删除）置底并标红。
3. **状态/模式标签色彩**：状态标签（已绑定绿/保留橙/空闲灰）与模式标签统一 Semi Tag 配色，替代 Element Plus type 映射。
4. **编辑约束前置**：已绑定行的 IP 与状态字段在表单内禁用并附提示（旧版仅依赖后端报错）。
5. **数据加载语义保持**：进入页面并行加载公网 IP 列表 + 用户列表 + VM 列表；任务提交后延迟刷新语义与旧版一致。
