# 安装时基础网络网段自动避让

QVMConsole 安装脚本会在首次写入 `KVM_SUBNET_PREFIX` 前检查宿主机已有 IPv4 网卡网段，避免系统基础网络默认使用 `192.168.122.0/24` 时与宿主机网络冲突。

## 规则

- 仅在首次安装或配置文件中没有 `KVM_SUBNET_PREFIX` 时自动选择网段。
- 如果 `192.168.122.0/24` 与任意非 `lo` 网卡的 IPv4 CIDR 重叠，会自动尝试下一个候选 `/24` 网段。
- 如果用户已经在 `.env` 中配置了 `KVM_SUBNET_PREFIX`，安装脚本会保留该值，不会自动改动，避免影响已有虚拟机。
- `KVM_OVS_DHCP_START` 与 `KVM_OVS_DHCP_END` 留空时会跟随最终选中的网段自动使用 `.2` 到 `.254`。

## 日志示例

当默认网段冲突时，安装日志会显示类似：

```bash
[WARN] 检测到默认基础网络 192.168.122.0/24 与宿主机网卡 eth0 192.168.122.10/24 冲突，已自动改用 192.168.123.0/24
```

安装完成后可查看：

```bash
grep '^KVM_SUBNET_PREFIX=' /opt/kvm-console/.env
```

## 手动指定

如需固定基础网络网段，可在安装前或修复配置前写入：

```bash
KVM_SUBNET_PREFIX=192.168.200
```

该值表示 `192.168.200.0/24`，网关会使用 `192.168.200.1`。
