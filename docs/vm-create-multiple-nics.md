# 创建虚拟机时配置多网卡

## 适用范围

创建向导的 ISO 安装、模板单台克隆、模板批量克隆和原生链式克隆均支持在“网络设置”步骤添加多个网口。

## 配置方式

1. 在“网络设置”中点击“添加网口”。
2. 为每个网口选择网卡型号、VPC 交换机和可选安全组。
3. 第一个有效网口作为主网口，其余网口通过 `extra_nics` 随创建任务提交。
4. q35 虚拟机会默认预留 6 个 PCIe 根端口；当额外网卡、磁盘或直通设备需要更多端口时，后端会自动提高创建时的最低端口数，最大为 32 个。

端口安全总开关开启时，每个网口都会显示允许地址设置。直通桥 IPv4 地址留空表示兼容保护，填写后执行精确校验；直通桥启用 IPv6 防护后，对应网口的精确 IPv6 地址为必填并须属于交换机可信前缀。字段同步适用于 ISO 创建、模板克隆、批量克隆和导入链路。

## 失败反馈

额外网卡附加失败时，单台创建任务会明确返回失败原因；批量克隆会在对应虚拟机结果中记录失败，不再只写入后台警告后将任务显示为完整成功。

常见的 `No more available PCI slots` 表示现有虚拟机的 PCIe 根端口已经用尽。新创建的虚拟机会自动预留足够端口；已有虚拟机需要先关机，在编辑页增加“PCIe 热插槽”数量后再添加网口。

## 验证

在宿主机执行：

```bash
virsh domiflist <虚拟机名称>
virsh dumpxml --inactive <虚拟机名称>
```

`domiflist` 中的网卡数量应与创建时选择的有效网口数量一致，持久化 XML 中应存在对应数量的 `<interface>` 节点。

## 编辑已有网口

在虚拟机编辑页修改任意网口的 VPC 交换机后，系统会保留该网口的 MAC、网卡型号、Open vSwitch interface ID 和带宽配置，并同步更新运行态与持久化 XML。

- 虚拟机运行中时，系统通过热拔插切换该网口，网口会短暂断链；热插或持久化失败会恢复原网口与原交换机。
- 虚拟机关机时，系统仅更新持久化 XML，下一次开机生效。
