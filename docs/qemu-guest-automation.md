# QEMU Guest Agent 来宾自动化

## 功能入口

- **磁盘扩容**：虚拟机编辑页的系统盘扩容弹窗中，可在 Linux 运行态选择“自动扩容系统分区”。
- **新数据盘**：Linux 或 Windows 虚拟机运行且 QEMU Guest Agent 在线时，新建磁盘可选择自动初始化和挂载。
- **已有数据盘**：关联“我的存储”磁盘或管理员导入磁盘时，可选择自动识别并挂载已有数据卷。
- **模板克隆**：单台和批量模板克隆的额外磁盘可启用自动挂载；ISO 安装流程在系统安装完成后再从编辑页操作。
- **密码重置**：运行态通过 QEMU Guest Agent 在线处理，关机态继续使用离线流程；执行模式默认自动选择。

## Linux 行为

- 文件系统范围为 ext4、XFS、Btrfs，新空盘默认使用 ext4。
- 新空盘初始化为 GPT 单分区，默认挂载目录为 `/data`；多卷使用 `/data2`、`/data3` 等后缀。
- 持久挂载按 UUID 写入 `/etc/fstab`，使用 `defaults,nofail`，更新前生成带时间戳的备份并原子替换。
- 数据卷枚举使用兼容新版 `util-linux lsblk` 的参数组合，并通过 `blkid` 重新读取格式化后的文件系统；新空盘至少成功挂载一个卷后任务才会标记来宾阶段成功。
- 磁盘管理页的来宾挂载入口需明确选择“保留已有数据”或“初始化空盘”；Linux 初始化可选择 ext4、XFS、Btrfs，Windows 初始化固定使用 NTFS。已有模式未发现数据卷时返回可重试失败，初始化模式会清理同一挂载点上已失效的旧 UUID 配置。
- 初始化前先检查磁盘及其子卷的挂载状态：文件系统与目标目录完全匹配时按幂等成功处理并补齐 `fstab`，存在其他挂载关系时在修改分区表前终止任务并返回实际卷信息。
- 已有盘只挂载未使用的 ext4、XFS、Btrfs 数据卷；系统、EFI、恢复、swap、加密、RAID 和其他格式会跳过并写入任务警告。
- 系统盘扩容支持普通分区和 LVM：分区扩展后分别调用 `resize2fs`、`xfs_growfs` 或 `btrfs filesystem resize max`。
- 判断根分区是否位于磁盘末尾时使用分区起始扇区，而非分区编号或 `lsblk` 展示顺序；兼容云镜像常见的低扇区 `vda14`/`vda15` 启动分区与高扇区 `vda1` 根分区布局。
- 来宾扩容重试允许 `growpart` 返回 `NOCHANGE`，随后继续校准文件系统容量，避免宿主机或分区阶段已完成时把幂等重试误判为失败。
- 多设备 Btrfs、根分区不在磁盘末尾或磁盘映射不明确时，宿主机扩容结果保留，任务标记来宾阶段可重试。

## Windows 行为

- 新空盘初始化为 GPT、单分区并格式化为 NTFS。
- 已有盘识别全部合格的 NTFS/ReFS 数据卷，首卷优先使用指定盘符，其余卷自动分配 D 到 Z 的空闲盘符。
- 系统、启动、EFI、恢复及只读卷会跳过并写入任务结果。

## 前置条件与任务结果

- 虚拟机 XML 已配置 QEMU Guest Agent 通道，来宾内 `qemu-guest-agent` 服务正在运行。
- 来宾磁盘自动化要求虚拟机处于运行状态；创建或关联磁盘前会先检查 QGA 连接和命令能力。
- 任务结果包含 `host_stage`、`guest_stage`、`device`、`volumes`、`warnings`、`retryable`。宿主机阶段成功而来宾阶段失败时，可调用磁盘的 `guest-mount` 或 `guest-grow` 接口重试。
- 同一虚拟机的磁盘自动化和密码重置操作串行执行，避免并发修改分区、挂载表或凭据。
- QGA 请求统一编码为 ASCII JSON Unicode 转义格式，兼容会拒绝原始 UTF-8 JSON 字符串的旧版 QEMU Guest Agent；中文脚本提示、路径和密码在来宾侧仍按原内容传递。
