# 虚拟机详情页（新前端）

> 对应路由：`/vm/detail/:id`（`:id` 为虚拟机名称）
> 源码目录：`web/src/views/vm/detail/`
> 设计稿：`plan/vm-detail-concept.html`（布局参考，实际遵循 Semi Design 风格）

## 功能总览

| 功能 | 说明 |
|------|------|
| 实时详情 | 进入页面即建立详情 SSE 长连接（`/vm/:name/sse`，3s 间隔推送全量详情），断线 5 秒自动重连；网络/磁盘累计字节由前端增量计算速率 |
| Hero 三卡 | 状态卡（电源操作 + 锁定/救援/重装/编辑备注）、资源卡（CPU/内存计量条 + 网络/磁盘 IO + 配置摘要）、VNC 预览卡（截帧） |
| 页面标签 | 详情页注册到顶部标签栏，标题为虚拟机名，圆点随运行状态变色；同时写入「最近访问」供侧边栏快速切换 |
| 功能标签页 | 系统信息 / 快照管理 / 网络管理 / 定时任务 / VNC 控制台 / SPICE 控制台 / 编辑（占位），`lazyRender` 惰性挂载 |
| 监控图表 | 页面底部四图（CPU / 内存 / 网络 / 磁盘 IO），实时监控（SSE 驱动）+ 历史查询（日期范围 / 近 24 小时）双模式 |
| 磁盘双单位 | 磁盘 IO 在 IOPS ↔ 吞吐量之间一键切换（Hero 资源卡与监控图联动） |

## Hero 状态卡

- 状态图标（运行脉冲环 / 暂停 / 关机 / 迁移中旋转）+ 状态文案 + 已锁定 / 救援中标签 + 连续运行时长
- 电源操作（按状态分支）：
  - 非运行：开机（暂停态为「继续启动」）；暂停态额外提供「重置」
  - 运行中：重启 / 关机 / 强制断电；已锁定时关机与断电弹二次确认
  - 迁移中：展示提示条，禁用全部操作
- 快捷操作：锁定 / 解除锁定（解锁触发 428 高风险验证，由请求层自动处理）、救援模式（启动/关闭需重启确认）、重装系统、编辑备注（复用列表页弹窗）

## Hero VNC 预览卡

- 显示当前一帧 VNC 画面：临时建立 viewOnly RFB 连接截取首帧导出 JPEG，每 20 秒自动刷新，也可手动点击刷新
- 悬停显示「打开独立 VNC 页面」按钮，点击以独立浏览器窗口打开 `/vm/:id/vnc-window`
- 状态覆盖：未配置显示设备（`video_model=none`）/ VNC 未开启（提供「前往开启」跳转 VNC 标签页）/ 虚拟机未运行

## 功能标签页

### 系统信息（默认）
- 基本配置：CPU / 内存（动态/弹性内存提示）/ PCIe 热插槽用量（q35/virt 机型，余量 ≤1 警告）/ 系统磁盘（缺失警告）/ 操作系统 / 机器类型 / 模板来源 / 备注 / 连续运行
- 登录凭证：用户名 / 密码（密码默认隐藏，可按需显示，可复制，HTTP 降级复制）+ 离线重置密码（Linux/Windows/fnOS + 关机态可用，含强度校验与 HIBP 泄露检测）+ 重装系统入口
- 网络与连接：IP（桥接/关机不可获取提示）/ 全部网口 IP（含来源标签，超过 3 条折叠）/ 公网 IP / VNC 端口 / 网络接口 / 显示设备
- 高级设置：开机自启 / 启动冻结 / APIC / PAE / Guest Agent 状态 / CPU 限制 / CPU 亲和性 / 内存策略
- 磁盘 IOPS 限制（非轻量云）：设备 / 容量 / 总读写 IOPS 表，支持手动刷新

### 快照管理
- 列表：名称 / 创建时间 / 类型（内部/外部）/ 状态 / 描述 / 操作（当前标记 / 恢复 / 删除）
- 创建：描述 + 内存快照（运行时可选，暂停后创建或不主动暂停两种模式）；UEFI NVRAM 需修复时自动弹确认并可一键修复后继续创建
- 恢复/删除：外部快照与含子快照均有专门提示文案；支持删除全部快照
- 配额：标签页标题栏显示 `已用/上限` 徽标，达到上限禁用创建按钮

### 网络管理
- 端口转发：规则列表（协议/宿主机端口/完整访问地址复制/目标/入站区域限制开关（管理员）/编辑/删除）、添加（目标 IP 候选：静态绑定+DHCP+手动映射，支持自定义；宿主机端口留空自动分配；协议 TCP/UDP/TCP+UDP）、批量删除；首次使用引导（未固定 IP 时展示，点击「立即开通」自动绑定静态 IP）。注：建站扫描（HTTP 探测/封禁/白名单）功能已整体移除
- 静态 IP：静态绑定列表（解绑）+ DHCP 租约列表（只读）+ 绑定对话框（选租约或自定义）；桥接直通交换机显示提示并禁用
- 运行状态（管理员）：OVS 网桥 / 接口表（ofport / VirtualPort / IP 来源 / 异常）/ 带宽配置详情（QoS / Queue / tc）
- 网络诊断（管理员）：诊断摘要 + 抓包表单（接口 / 协议模板 / 五元组 / 时长 / 大小 / 包数，模板一键填充）+ 会话管理（启动需高风险确认 / 取消 / 下载 pcap / 删除 pcap + 实时摘要 2s 轮询 + 邻居表）

### 定时任务
- 一次性 / 每天 / 每周（可多选星期）三种计划；动作：开机 / 关机 / 删除虚拟机（删除仅支持一次性，触发 428 二次验证）
- 列表：事件类型 / 动作 / 执行计划（含时区）/ 下次执行 / 最近执行 / 最近结果（含任务 ID）/ 启用开关 / 编辑 / 删除

### VNC 控制台（管理）
- 状态标签（未开启 / 已开启 + 认证方式 + 已对外暴露 + 端口）
- 开启（可设密码，需重启生效）/ 关闭 / 修改密码（即时生效）/ 对外暴露（高风险确认，需重启生效）
- 「打开独立 VNC 窗口」主按钮，独立窗口功能见下文

### SPICE 控制台
- 状态标签（未开启 / 仅本地 / 已对外暴露）+ 端口 / 外部地址（暴露时）
- 开启 / 关闭 / 修改密码 / 对外暴露开关（高风险确认，联动宿主防火墙）
- .vv 连接文件下载（一次性 / 可重复使用；虚拟机关机时禁用并提示）

### 编辑
- 复用 `features/vm-form` 共享表单实现（与创建向导同一套模型/规则/分区组件），选项卡：基础配置 / 磁盘与驱动器 / 启动与安全 / 网口管理 / 硬件直通（仅管理员） / 高级设置
- 网口管理：主网口 VPC 绑定切换（交换机/安全组，轻量云禁用，运行中提示重新获取 DHCP）+ 多网口列表（添加/编辑/删除网口仅管理员，运行态实时 IP，多网口热插拔提示）
- 差异快照提交：加载时捕获表单与磁盘 IOPS 快照，保存时仅发送变化字段，避免后端无谓的 virsh XML 读写
- 运行态约束：CPU/内存热插拔（未启用热添加时禁止改 CPU）；引导方式/网卡类型/显示设备/SPICE 需关机修改
- 磁盘管理：扩容（仅扩大）/ 删除（连文件删除或转移到我的存储）/ 驱动切换（关机）/ 新建磁盘 / 挂载已有磁盘（管理员支持绝对路径导入）/ IOPS 限制（仅管理员，保存时统一提交）
- 光驱与软盘：插入 / 弹出 / 移除 / 新增设备（运行中新增光驱自动改用支持热插的 SCSI 总线）
- SPICE 联动：开关状态变化时随保存自动启用/禁用；XML 编辑器可直接查看与保存持久化 domain XML

## VNC 独立窗口（`/vm/:id/vnc-window`）

- 独立于主框架的全屏暗色页面，通过 `window.open` 以独立浏览器窗口打开
- 工具栏：连接 / 断开 / Ctrl+Alt+Del / 常用组合键（Ctrl+Shift+Esc、Alt+Tab、Win+R、Ctrl+Alt+F1/F2、Ctrl+Alt+Backspace）/ 粘贴密码（读取已保存凭据逐字符输入）/ 发送文本 / 全屏 / 关闭窗口
- 打开后自动获取凭据并自动连接；VNC 密码认证弹原生 prompt
- 窗口标题自动同步为「VNC - 虚拟机名」

## 联动

- 列表页（`/vm`）表格与卡片视图的虚拟机名称均可点击跳转详情页
- 侧边栏「虚拟机」菜单下展示最近访问的 6 台虚拟机（状态圆点），点击直达详情页
- 详情页内的备注/重装弹窗直接复用列表页组件（通过 `detailToListItem` 适配类型）

## 响应式

| 断点 | 行为 |
|------|------|
| ≤1280px | Hero 三卡列宽微调 |
| ≤1180px | Hero 变两列，VNC 预览卡独占一行 |
| ≤820px | Hero / 信息卡 / 监控图 / 诊断表单全部单列，返回顶部按钮内收 |
