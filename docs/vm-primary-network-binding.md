# 虚拟机主网口绑定

适用范围：编辑页「网口管理」中的主网口 VPC 绑定。

## 行为

- 虚拟机已有实体网卡时，系统将该主网卡切换到选定的 VPC 交换机和安全组。
- 虚拟机没有实体网卡时，系统会先创建并挂入主网卡，再保存 VPC 绑定记录，避免页面显示已绑定但来宾系统没有网卡。
- 所有来宾创建主网卡时统一使用 `virtio`。
- 运行中的虚拟机使用热插拔。若 libvirt 或来宾系统不支持热插拔，接口会返回失败，绑定记录不会写入；可关机后再次保存绑定。
- 普通开机前会按主网口 VPC 绑定同步虚拟机持久化 XML。若历史配置中绑定记录已切回普通 VPC、但 XML 主网卡仍停留在桥接直通网桥，系统会先在关机态修正 XML，再启动虚拟机，避免启动成功后才触发“从桥接直通交换机切换回 VPC 需要先关闭虚拟机”的运行态限制。

## 运行态限制

从桥接直通交换机切回普通 VPC 会改变虚拟机主网口的宿主机桥接来源，运行中的虚拟机不做强制热切换。若虚拟机已经因为旧流程启动成功但网络应用失败，请先在面板中关闭该虚拟机，再重新开机；新的启动流程会在开机前同步 XML。

多网口虚拟机只按主网口判断上述运行态限制。附加网口可以继续使用桥接直通交换机，不会被主网口的普通 VPC 运行态刷新误判为需要关机切换。

## 验证

在宿主机执行以下命令可确认网卡已进入虚拟机：

```bash
virsh domiflist <虚拟机名称>
```

输出应至少包含一条网口。Windows 中可在设备管理器的「网络适配器」查看新增网卡；若运行态未及时刷新，可执行“扫描检测硬件改动”或重启虚拟机。
