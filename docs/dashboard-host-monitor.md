# 工作台宿主机资源监控（设备级流量/IO 查看）

> 对应路由：工作台（管理员仪表盘）`/dashboard`
> 源码目录：
> - 前端：`web/src/views/dashboard/components/HostMonitorCharts.tsx`
> - 后端：`server/service/vm/stats.go`（采集汇总）、`server/service/host/net.go`（物理网卡采集）、`server/service/host/disk.go`（物理硬盘采集）、`server/service/host/stats_collector.go`（历史持久化）

## 功能总览

| 功能 | 说明 |
|------|------|
| 网络流量设备选择 | 资源监控的「网络流量」卡片顶部提供网卡下拉框，可选择查看**全部网卡汇总**或**具体某块物理网卡**的收发流量 |
| 磁盘 IO 设备选择 | 资源监控的「磁盘 I/O」卡片顶部提供硬盘下拉框，可选择查看**全部硬盘汇总**或**具体某块物理硬盘**的读写 IO |
| 实时/历史双模式 | 设备选择在「实时监控」与「历史查询」两种模式下同时生效；历史查询时切换设备会立即基于最近一次查询结果重绘曲线 |
| 历史记录包含设备数据 | 宿主机历史监控记录（`host_stats_records` 表）随汇总值一并持久化**每个物理网卡/物理硬盘的累计值**（JSON 列），历史图表可还原任意设备在任意时间段的流量/IO 趋势 |
| 设备自动同步 | 下拉选项随实时数据自动刷新（SSE 每 5 秒推送）；设备不存在（如网卡拔除）时自动退回「全部」 |

## 使用说明

1. 管理员登录后进入「工作台」；
2. 在「资源监控」区域，网络流量卡片左上角选择网卡：
   - **全部网卡**（默认）：显示所有物理网卡收发流量之和；
   - 具体网卡（如 `enp3s0`、`eth0`）：仅显示该网卡流量；
3. 磁盘 I/O 卡片左上角选择硬盘：
   - **全部硬盘**（默认）：显示所有物理硬盘读写之和；
   - 具体硬盘（如 `sda`、`nvme0n1`）：仅显示该硬盘读写 IO；
4. 切换到「历史查询」后，日期范围查询与「近 24 小时」查询结果同样按当前所选设备渲染；切换设备无需重新查询，曲线立即按新设备重绘。

## 数据来源与口径

### 物理网卡（`net_devices`）

- 读取 `/proc/net/dev` 枚举所有接口，仅保留**物理网卡**：
  - 排除虚拟接口前缀：`lo`、`virbr`、`vnet`、`veth`、`docker`、`br-`、`ovs`、`tap`、`tun`、`macvtap`、`gretap`、`dummy`、`vxlan`、`wg` 等；
  - 要求 `/sys/class/net/<name>/device` 符号链接存在（真实硬件设备才会创建，与网口管理/端口镜像模块的物理网卡判定一致）；
- 「全部网卡」汇总 = 各物理网卡之和（此前为 awk 汇总口径，排除规则更完整，避免网桥/容器接口重复计数）；
- 设备级采集失败时自动退回原有 awk 汇总口径（`net_rx_bytes`/`net_tx_bytes` 不受影响）。

### 物理硬盘（`disk_devices`）

- 设备列表优先来自 `lsblk -dn -o NAME,TYPE`（`type=disk` 的顶层设备），为空时退回 `/proc/diskstats` 常见磁盘名匹配（`sd*`/`vd*`/`nvme*`/`mmcblk*`/`md*` 等）；
- 每个设备的累计读写字节数来自 `/proc/diskstats`（扇区数 × 512）；
- 「全部硬盘」汇总 = 各物理硬盘之和，与原有汇总口径一致。

## 后端接口与数据格式

### `/host/stats`（实时，SSE `/host/stats/sse` 同结构）

在原有字段基础上新增：

```json
{
  "net_devices": [
    { "name": "enp3s0", "rx_bytes": 123456789, "tx_bytes": 987654321 }
  ],
  "disk_devices": [
    { "name": "sda", "rd_bytes": 123456, "wr_bytes": 654321 }
  ]
}
```

### `/host/stats/history`（历史查询）

每条记录的累计值字段之外新增 `net_devices` / `disk_devices` 数组（结构同上），由 `host_stats_records` 表的 `net_devices_json` / `disk_devices_json` 文本列反序列化而来。旧数据（升级前写入的记录）两列为空字符串，前端将自动降级为仅「全部」选项，不影响查询。

### 速率计算

- 实时：前端对所选设备的累计值做 5 秒窗口差分（KB/s）；
- 历史：前端对相邻两个记录点的累计值做时间差分（KB/s）；
- 切换设备或设备数据缺失时该点为 0，避免跨设备累计值造成假尖峰。

## 注意事项

- 历史记录持久化间隔为 60 秒（与原有汇总记录一致），新设备数据从升级后的下一条记录开始写入；
- 数据库表结构变更由 GORM `AutoMigrate` 自动完成（新增两列文本列），无需手工迁移；
- 网桥（`br-*`/OVS）与容器接口不计入「全部网卡」汇总，如需查看其流量请从网口管理/抓包工具查看。
